## ✨ ویژگی‌ها و قابلیت‌های پیاده‌سازی شده

در این پروژه، موارد زیر به طور کامل پیاده‌سازی و توسعه داده شده است:

- 📊 **گزارش‌گیری:** گرفتن خروجی اکسل (Excel) و پی‌دی‌اف (PDF) از سفارشات.
- 🗂 **مدیریت محصولات:** اضافه کردن و پیاده‌سازی سیستم دسته‌بندی محصولات.
- 🔐 **احراز هویت:** اضافه کردن سیستم ثبت‌نام و ورود با کد تایید (OTP).
- 📅 **مدیریت زمان:** اضافه کردن سیستم تقویم و مدیریت تعطیلات مجموعه.
- ⏰ **فرآیند سفارش:** اضافه کردن سیستم انتخاب زمان تحویل برای سفارشات توسط کاربر.
- 💳 **پرداخت:** اضافه کردن و اتصال درگاه پرداخت آنلاین.
- 🚚 **لجستیک:** اضافه کردن سیستم مسیریابی برای بارها و محموله‌های مجموعه.
- 🏷 **تخفیفات:** اضافه کردن سیستم تخفیفات بر روی محصولات.
- 🎨 **رابط کاربری:** تغییرات گسترده و بهبود روی فرانت‌اند (UI/UX).
